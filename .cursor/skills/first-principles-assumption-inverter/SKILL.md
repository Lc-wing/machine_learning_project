# 底层公理反转器（First-Principles Assumption Inverter）

**核心定位**：挑战常识，从"显而易见但未被证明"的前提中寻找突破口。

用户给出一个研究方向（例如"长序列建模"、"联邦学习"、"扩散模型采样"），按下面三个阶段工作，最后按"输出模板"交付。

## 硬性规则

- **不得编造文献**。每一篇引用的论文都必须是检索确认过的，附标题、会议/期刊、年份和链接（arXiv / OpenReview / DOI）。无法核实的内容标注"待核实"。
- **不立稻草人**。被反转的前提必须是主流工作真实采用的，要能指出它具体落在哪些论文的哪些设计里（架构、损失、训练流程、评测协议）。
- **命题必须可证伪**。每个新命题都要附带一个能证明它错的最小实验。
- 用户没有指定时，默认时间窗为近 5 年，默认会议期刊按领域选（ML：NeurIPS / ICML / ICLR / JMLR / TPAMI；CV：CVPR / ICCV / ECCV；NLP：ACL / EMNLP / NAACL；数据挖掘：KDD / WWW）。

## 文献检索方式

可用 WebSearch / WebFetch 工具时优先使用：

- Semantic Scholar API：`https://api.semanticscholar.org/graph/v1/paper/search?query=<关键词>&year=2021-2026&fields=title,venue,year,citationCount,abstract,externalIds&limit=50`
- arXiv API：`http://export.arxiv.org/api/query?search_query=all:<关键词>&sortBy=relevance&max_results=50`
- OpenReview（ICLR / NeurIPS 等，可以看到审稿意见）、CVF Open Access、ACL Anthology
- 先找综述和高引论文定位主流范式，再补近 1–2 年的最新工作

## 阶段一：公理列表提取

1. 检索 15–30 篇代表性论文（综述、高引论文、最佳论文、近期 SOTA）。
2. 找出它们**普遍默认但很少被单独论证或消融**的前提。重点看以下几类：
   - **架构类**：例如"网络越深表征越强"、"必须保留全局注意力"、"参数共享总是有益"
   - **数据/分布类**：例如"训练与测试独立同分布"、"噪声近似高斯"、"标签是干净的"
   - **优化/动力学类**：例如"系统必须处于均衡态"、"损失曲面足够平滑"、"更大 batch 只是更快"
   - **资源类**：例如"推理算力和显存充足"、"可以多次访问全部数据"
   - **评测类**：例如"基准分数提升等于能力提升"、"平均指标能反映最坏情况"
3. 判断一个前提是否属于"显而易见但未被证明"：
   - 被大多数工作直接沿用，论文里通常只有一句话或一个引用作为依据
   - 只有经验支持，没有理论保证，或者理论保证依赖很强的条件
   - 很少有论文专门消融或检验它
4. 最终保留 **3–5 条**，每条记录：前提表述、所属类别、采用它的代表论文（≥2 篇）、它在设计中的具体体现、已有支持证据、已知反例或质疑（如果有）。

## 阶段二：反向推演

对每条前提，强行设想它在某种**极端边缘工况**下失效。可选工况（按相关性挑 1–2 个，不要全部套用）：

| 工况 | 典型例子 |
|------|----------|
| 超低算力 / 显存 / 时延 | 边缘设备、MCU、实时控制、单样本推理 |
| 非高斯噪声 | 重尾噪声、脉冲噪声、对抗扰动、标签噪声 |
| 分布剧烈漂移 | 协变量漂移、概念漂移、非平稳时序、开放世界 |
| 极端数据形态 | 极少样本、极端长尾、超长序列、高缺失率、多模态缺失 |
| 非均衡 / 非稳态 | 持续学习、多智能体博弈、在线反馈回路 |
| 极端规模 | 超大模型或超小模型、超大图、超高分辨率 |

每条推演要写清楚：

1. **失效机制**：前提在该工况下**为什么**失效，给出机制层面的解释（理论推导、简化模型或已有实证），而不是只说"可能不好"。
2. **可观测症状**：失效时会出现什么现象（指标断崖、梯度异常、校准崩坏、方差爆炸等）。
3. **最小验证实验**：用最低成本复现该失效的实验设计（数据集、控制变量、预期曲线）。

## 阶段三：输出新命题

倒推前提被打破后，系统需要引入什么样的**新归纳偏置**。常见的候选方向（仅作启发，不要机械套用）：局部性、稀疏性、等变/不变性、因果不变性、鲁棒统计（如 Huber 损失、中位数聚合）、自适应/在线更新、层级结构、显式记忆、物理或能量约束、不确定性建模、计算预算感知。

每个新命题按以下格式写：

> **命题**：在工况 R 下，主流前提 A 失效，原因是机制 M；引入归纳偏置 B 的模型，将在指标 X 上显著优于遵循 A 的基线。
> **可证伪预测**：如果 [具体实验结果]，则命题不成立。
> **最小验证实验**：数据集、基线、变量、预期结果、大致算力需求。
> **最接近的已有工作**：列出 1–3 篇，说明本命题与它们的本质区别。

## 自检（交付前必须完成）

- [ ] **新颖性**：针对每个命题再检索一次"已经反转过该前提的工作"（检索词示例：`rethinking <前提>`、`is <机制> necessary`、`<前提> fails under <工况>`）。若已有人做过，要么说明差异，要么删掉。
- [ ] **非稻草人**：每条前提都有 ≥2 篇主流论文作为采用证据。
- [ ] **可行性**：最小验证实验在普通学术算力（如 1–8 张消费级或数据中心 GPU）下可以完成，否则要说明。
- [ ] **非 A+B**：新命题不能只是"把方法 A 和方法 B 拼在一起"，必须来自对前提失效机制的推导。
