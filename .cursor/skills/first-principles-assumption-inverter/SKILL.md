# 底层公理反转器（First-Principles Assumption Inverter）

**核心定位**：挑战常识，从"显而易见但未被证明"的前提中寻找突破口。

**输入**：一个研究方向（例如"长序列建模"、"联邦学习"、"扩散模型采样"）。用户没给方向时先问清楚。可选：指定会议期刊、时间窗、目标工况（如"边缘设备部署"）、深度。

**深度**：默认"标准模式"（约 20 篇语料、3–5 条前提、每条前提推演 1–2 个工况）。用户要求快速时用约 10 篇、3 条前提；要求全面时用 30 篇以上。

## 硬性规则

1. **不编造文献**。每篇引用的论文都要检索确认过，附标题、会议/期刊、年份、链接。没核实的标注"待核实"。
2. **不立稻草人**。被反转的前提必须是主流工作真实采用的，每条至少指出 2 篇主流论文，以及它落在这些论文的哪个设计里（架构、损失、训练流程、数据假设、评测协议）。
3. **命题必须可证伪**。每个新命题都附带一个能证明它错的最小实验。
4. **推演要讲机制**。"在极端条件下可能不好"不算推演，必须说清楚为什么失效。
5. 默认时间窗为近 5 年。默认会议期刊按领域选：ML 用 NeurIPS / ICML / ICLR / JMLR / TMLR / TPAMI；CV 用 CVPR / ICCV / ECCV；NLP 用 ACL / EMNLP / NAACL；数据挖掘用 KDD / WWW。

## 工具

复用 `gap-contradiction-miner` 自带的两个脚本（只依赖 Python 标准库）：

```bash
# 检索：按年份、会议过滤，按引用数排序，用来找主流范式的代表作
python3 .cursor/skills/gap-contradiction-miner/scripts/find_papers.py search '"long context" +transformer' \
  --year 2021- --venue NeurIPS,ICML,ICLR --limit 30

# 读方法和实验设置：隐含前提通常藏在这些章节里
python3 .cursor/skills/gap-contradiction-miner/scripts/extract_sections.py 2312.00752 \
  --pattern "preliminar|background|state space|method|approach|setup|implementation|experimental detail" --max-chars 8000

# 新颖性核查：查有没有人已经反转过同一个前提
python3 .cursor/skills/gap-contradiction-miner/scripts/find_papers.py search 'rethinking +"<前提关键词>"' --year 2021-
```

检索结果的 Year 是首次发表年份（常为 arXiv 年份），引用会议年份前要核实。各论文的章节命名差异很大，`--pattern` 要按领域调整；没匹配到时脚本会列出顶层章节标题供参考。没有 `S2_API_KEY` 时检索要串行执行，避免触发限速。脚本不可用时，退回 WebSearch / WebFetch，直接读取 Semantic Scholar API、arXiv、OpenReview。

## 校准案例：什么样的反转有价值

| 被反转的前提 | 反转它的工作 | 打破后的新认识 |
|--------------|--------------|----------------|
| 深度网络泛化好，是因为模型容量或正则化限制了它去记忆数据 | Zhang et al., "Understanding deep learning requires rethinking generalization" (ICLR 2017)：网络能完美拟合随机标签，去掉显式正则化依然泛化 | 泛化不能只用容量解释，需要研究优化过程带来的隐式偏置 |
| 模型超过一定规模后，参数越多越容易过拟合（经典 U 形曲线） | Nakkiran et al., "Deep Double Descent" (ICLR 2020)：越过插值阈值后测试误差再次下降 | 需要用"有效模型复杂度"重新理解规模与泛化 |
| Vision Transformer 胜过卷积网络，是因为注意力机制本身 | Liu et al., "A ConvNet for the 2020s" (CVPR 2022)：现代化改造后的纯卷积网络 ConvNeXt 可与 Swin Transformer 匹敌 | 很大一部分收益来自训练配方和宏观设计，"注意力更强"这一前提混淆了变量 |
| 要做好语言等离散序列建模，必须有全局注意力 | Gu & Dao, "Mamba" (COLM 2024)：选择性状态空间模型在其测试规模上与同规模 Transformer 相当，且复杂度对序列长度是线性的 | 新的归纳偏置是"依赖输入的选择性状态压缩" |

共同点：被反转的前提都曾被当作常识，反转后都带来了新的机制解释或新的归纳偏置，而不只是一个新模型。

## 工作流程

### 阶段零：确定范围，建立语料

用 `find_papers.py search` 组合几组关键词，找出该方向近 5 年的综述、高引论文和最新代表作，挑出 15–30 篇作为语料。

### 阶段一：公理列表提取

1. **按类别排查隐含前提**：
   - **架构类**：例如"网络越深表征越强"、"必须保留全局注意力"、"参数共享总是有益"
   - **数据/分布类**：例如"训练与测试独立同分布"、"噪声近似高斯"、"标签基本干净"
   - **优化/动力学类**：例如"系统处于或趋于均衡态"、"损失曲面足够平滑"、"更大 batch 只是更快"
   - **资源类**：例如"推理时算力和显存充足"、"可以多次访问全部数据"
   - **评测类**：例如"基准分数提升等于能力提升"、"平均指标能代表最坏情况"
   - **问题定义类**：例如"任务目标是固定的"、"输入模态总是齐全的"
2. **识别"显而易见但未被证明"的信号**：
   - 论文中出现 "following prior work"、"as is standard"、"as is common practice"、"we assume"、"without loss of generality" 一类措辞
   - 只有经验支持，没有理论保证；或理论保证依赖很强的条件
   - 被大多数工作沿用，却很少有人专门消融或检验
3. **保留 3–5 条**，每条记录：前提表述、类别、采用它的代表论文（至少 2 篇）及其具体体现、支持证据、已知质疑（如果有）。

### 阶段二：反向推演

1. **选择反转方式**（每条前提选最有意义的一种）：
   - **否定**：A 成立 → A 不成立
   - **弱化**：总是成立 → 只在某些条件下成立
   - **反向**：越多越好 → 越少越好，或存在最优点
   - **常量变变量**：固定不变 → 随时间、环境变化
   - **推向极端**：把某个量推到接近 0 或接近无穷
2. **选择极端边缘工况**（挑与前提最相关的 1–2 个，不要全部套用）：

   | 工况 | 典型例子 |
   |------|----------|
   | 超低算力、显存、时延 | 边缘设备、MCU、实时控制、单样本推理 |
   | 非高斯噪声 | 重尾噪声、脉冲噪声、对抗扰动、系统性标签噪声 |
   | 分布剧烈漂移 | 协变量漂移、概念漂移、非平稳时序、开放世界 |
   | 极端数据形态 | 极少样本、极端长尾、超长序列、高缺失率、模态缺失 |
   | 非均衡、非稳态 | 持续学习、多智能体博弈、带反馈回路的在线系统 |
   | 极端规模 | 超大或超小模型、超大图、超高分辨率 |

3. **每条推演写清楚**：
   - **失效机制**：为什么失效。证据强度从高到低依次为理论推导、简化模型（toy model）分析、已有实证；标明属于哪一种。
   - **可观测症状**：失效时会出现的现象，例如指标断崖、梯度异常、校准崩坏、方差爆炸、性能随某个量非单调变化。
   - **最小验证实验**：用最低成本复现失效的设计，包括数据集、控制变量、预期曲线，最好在单张 GPU 上能完成。

### 阶段三：输出新命题

倒推前提被打破后，系统需要引入什么样的**新归纳偏置**。下表仅作启发，不要机械套用：

| 失效来源 | 候选归纳偏置 |
|----------|--------------|
| 算力、显存极低 | 稀疏性、条件计算、早退、局部性、低秩结构 |
| 重尾、脉冲噪声 | 鲁棒损失（如 Huber、截断损失）、中位数或截尾均值聚合、梯度裁剪、重尾先验 |
| 分布漂移 | 不变性或因果特征、测试时自适应、在线更新、不确定性估计 |
| 长尾、少样本 | 结构化先验、组合性、元学习、检索增强 |
| 非平稳、非均衡 | 显式记忆、可塑性保持、动力系统建模 |
| 超长序列 | 选择性状态压缩、层级或分块结构、局部加稀疏全局交互 |

每个命题按以下格式写：

> **命题**：在工况 R 下，主流前提 A 失效，原因是机制 M；引入归纳偏置 B 的模型，将在指标 X 上显著优于遵循 A 的基线。
> **可证伪预测**：如果出现 [具体实验结果]，则命题不成立。
> **最小验证实验**：数据集、基线、自变量、预期结果、大致算力需求。
> **最接近的已有工作**：1–3 篇，说明本命题与它们的本质区别。

### 阶段四：自检（交付前必须完成）

- [ ] **新颖性**：对每个命题检索一次是否已有人反转过同一前提，检索词如 `rethinking <前提>`、`is <机制> necessary`、`<机制> fails under <工况>`、`beyond <前提>`。已有人做过的，要么说明差异，要么删除。
- [ ] **非稻草人**：每条前提都有至少 2 篇主流论文作为采用证据。
- [ ] **讲机制**：每条推演都给出了失效机制，并标明了证据强度。
- [ ] **可行性**：最小验证实验在普通学术算力下能完成，做不到的要说明。
- [ ] **非 A+B**：新命题来自对失效机制的推导，而不是"把方法 A 和方法 B 拼起来"。

## 与文献空白与矛盾捕获器配合

如果 `gap-contradiction-miner` 已经找到一组真矛盾，矛盾双方共享的隐含前提往往就是很好的反转对象，可以直接作为阶段一的输入。反过来，本 skill 推出的新命题，也可以交给它核查是否已有人做过、是否与已知的局限性相呼应。
