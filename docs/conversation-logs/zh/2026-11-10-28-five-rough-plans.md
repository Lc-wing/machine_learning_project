# 28 为其余五个方向各写一页英文研究计划

- 日期：2026-11-10
- 承接：[10](2026-10-21-10-sketchthinker-future-directions.md)、[24](2026-11-10-24-replace-direction-11.md)、[27](2026-11-10-27-revise-one-page-plan.md)
- 问题：使用相关科研技能，按与现有一页计划相同的要求，为剩下的五个研究方向各写一份全英文的粗略研究计划。
- 英文版：[点此查看](../en/2026-11-10-28-five-rough-plans.md)

## 结果

五份计划都在 `docs/research-plan/`，HTML 与 PDF 成对。导出后每份 PDF 的页数都是 1。结构与已修订的充分性计划相同：暂定标题、一两句问题陈述、一段方案、两到三个研究问题、一句预期结果，并各附一张对照表。看见图像的充分性不再重复。

| 文件 | 方向 |
|------|------|
| `difficulty-boundary` | 简洁从哪一级难度开始有害 |
| `matched-source` | 对齐改写来源和风格奖励之后，收益还在不在 |
| `twice-used-premise` | 编号列表会不会丢掉被用两次的视觉前提 |
| `restore-probability` | 放回被删句子后答案概率是否应当不变 |
| `length-tail` | 平均词元下降是否把错误推进长度右尾 |

写法遵循底层公理反转器：每份都有可证伪的结果。也遵循文献空白与矛盾捕获器：最近的已有工作写在方案里，并说明为什么不能直接接上去。难度计划不使用 AdaptThink 的平均准确率开关。两次使用计划不使用只删冗余反思的图修剪。右尾计划不把 Sprint or Delve 的惩罚形式当成自己的贡献。概率计划在试点失败时不进入训练。来源识别计划只有同时胜过“保持原长度的改写”和“风格奖励为零”才把收益归于风格。
